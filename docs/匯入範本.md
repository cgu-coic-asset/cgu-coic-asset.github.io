# Excel 匯入範本

學校系統只給 PDF（固定資產「財產目錄（使用部門）」、保管品「個人保管工具明細表」）。用 `tools/pdf_to_excel.py` 把 PDF 轉成下面兩種格式的 Excel，再到系統匯入。手動整理或其他來源的資料，只要照這個格式也能匯入。

- 範例檔：[固定資產匯入範本.xlsx](匯入範本/固定資產匯入範本.xlsx)、[保管品匯入範本.xlsx](匯入範本/保管品匯入範本.xlsx)（資料都是虛構的；第二個分頁「欄位說明」）。
- 欄位定義的唯一來源是 `shared/importTemplate.js`；改欄位後執行 `python3 tools/make-import-templates.py` 重產範例檔。
- **轉好的 Excel 含學校資料，不要放進這個 repo。**

## PDF 轉 Excel

需要 Mac（或 Linux）安裝 `pdftotext`（`brew install poppler`）、Python 套件 `openpyxl`、Node.js。

```sh
# 固定資產（一份 PDF 含所有使用部門）
python3 tools/pdf_to_excel.py 20260413_固定資產清單.pdf -o 固定資產.xlsx
# 保管品（各部門的 PDF 一起給，合併成一個檔）
python3 tools/pdf_to_excel.py 20260525_D000_ALL個人保管品.pdf 20260401_D100_ALL個人保管品.pdf 20260401_DZ10_ALL個人保管品.pdf -o 保管品.xlsx
```

- 依每個字在頁面上的座標分欄，跨行的品名、存放位置會接回來；部門代號取每頁頁首。
- 轉完會自動跑一次匯入檢查，列出筆數、各部門筆數、錯誤與提醒。範本沒有的欄位（獎補助編號、附註、增值補充說明、數量不是 1、保管品的處理方式與移入）有值時也會列出來。
- 學校報表版面改了，要調整程式開頭的欄位範圍。

## 共同規則

- 讀第一個分頁；第 1 列是標題，資料從第 2 列開始。欄位順序不限，多出來的欄位會列出後略過。
- 標題可用「也接受的標題」裡的寫法，標題中的空白會被忽略。
- 儲存格請設成**文字**格式，否則 Excel 會把資產編號開頭的 0 去掉。
- 日期一律 `YYYYMMDD`（西元）。也接受 `2024/1/15`、`2024-01-15` 與 Excel 日期格式；民國年不接受。
- 保管人可以分兩欄（保管人代號、保管人姓名），也可以只給一欄「保管人」寫成 `D000000001 王小明`。
- 一列有「錯誤」就不會匯入那一列；「提醒」可以匯入，但要先看過。整份檔案缺必要欄位時整份不收。

## 固定資產

一列＝一個「資產編號＋增值次數」。增值紀錄另列一行，資產編號相同、增值次數不同。

| 欄位 | 必填 | 格式 | 說明／也接受的標題 |
| --- | --- | --- | --- |
| 資產編號 | ✔ | 代號 | 10 碼英數字（可含 `*`），開頭的 0 不可省略 |
| 增值次數 |  | 整數 | 空白視為 0／增值 |
| 資產名稱 | ✔ | 文字 |  |
| 廠牌規格 |  | 文字 | 廠牌、規格 |
| 產品序號 |  | 文字 | 序號 |
| 部門代號 |  | 代號 | **每頁**頁首的「使用部門」（同一份 PDF 有 D000、D100、D10W、DZ10）；空白時用系統設定的部門代號 |
| 存放位置 |  | 文字 | 位置 |
| 保管人代號 | ✔ | 代號 | 例 `D000000001` |
| 保管人姓名 |  | 文字 |  |
| 驗收取得日 |  | 日期 | 取得日期、驗收日期 |
| 取得價值 |  | 數字 | PDF 沒有，可留空／價值、金額 |
| 耐用年數 |  | 整數 | 耐用年限 |
| 保固期限 |  | 日期 | 保固到期日 |
| 研究計劃編號 |  | 文字 | 研究計畫編號 |
| 請購案號 |  | 代號 | PDF 第二行。與產品序號是不同欄位；沒有產品序號（空白或 N/A）的資產，畫面上以請購案號代替。學校有些資產本身就把請購案號填在產品序號 |

檢查：

| 規則 | 等級 |
| --- | --- |
| 資產編號、資產名稱、保管人代號空白 | 錯誤 |
| 同一個資產編號＋增值次數出現兩次 | 錯誤 |
| 增值次數、耐用年數不是整數；取得價值不是數字 | 錯誤 |
| 資產編號全是數字但不足 10 碼 → 自動在前面補 0 | 提醒 |
| 日期看不懂（保留原文） | 提醒 |
| 保管人代號格式少見、沒有姓名、同一代號出現不同姓名 | 提醒 |

## 保管品

一列＝一位保管人的一種材料。系統用 `保管人代號-材料編號` 當作保管品鍵（QR 網址 `?C` 後面接這個）。

| 欄位 | 必填 | 格式 | 說明／也接受的標題 |
| --- | --- | --- | --- |
| 部門代號 | ✔ | 代號 | PDF 頁首「保管部門」，例 D000、D100／保管部門 |
| 保管人代號 | ✔ | 代號 | 保管人員代號 |
| 保管人姓名 |  | 文字 | 保管人員姓名；PDF 偶爾沒有姓名 |
| 材料編號 | ✔ | 代號 |  |
| 品名規格 |  | 文字 | 跨行的品名規格合成一格／品名 |
| 單位 |  | 代號 | ST、PC… |
| 帳面數量 | ✔ | 數字 | PDF 的「保管量」，`3.0` 會存成 3／保管量、數量 |
| 來源最後異動日 |  | 日期 | 最後異動日 |

檢查：部門代號、保管人代號、材料編號、帳面數量空白或數量 ≤ 0 為錯誤；同一保管人＋材料編號出現兩次為錯誤；沒有品名規格、沒有姓名、同一代號不同姓名為提醒。

## 現有轉檔的對應結果（2026-11-13）

`智慧運算學院固定資產清單202604.xlsx`（先前用 AI 轉出，放在本機 school/Asset）丟進匯入檢查的結果：

- **欄位對得上**：資產編號、資產名稱、廠牌規格、存放位置、保管人（合併欄）、產品序號、驗收取得日、保固期限、耐用年數都能自動對應；ID、類別、財產照片、最後盤點日期會被略過；沒有增值次數（視為 0）和部門代號（只能全部用系統設定，但 PDF 其實分屬 4 個使用部門）。
- **內容不能直接用**：493 列中有 87 列重複（83 列完全相同）；和 PDF 比對，469 個資產編號少了 64 個；51 個資產編號開頭的 0 不見了；191 列的產品序號其實是請購案號，真正的序號被併進存放位置；同一保管人代號有兩種姓名。
- 結論：舊檔不用，改用轉檔程式。
- 改用 `tools/pdf_to_excel.py` 轉同一份 PDF：469 筆（＝PDF 的資產編號數），D000 102、D100 289、D10W 17、DZ10 61，匯入檢查錯誤 0、提醒 0。保管品三份 PDF 共 45 筆，錯誤 0，提醒 1（PDF 上有一位保管人沒有姓名）。
