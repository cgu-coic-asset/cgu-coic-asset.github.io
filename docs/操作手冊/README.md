## 名詞

| 名詞 | 意思 |
| --- | --- |
| 固定資產 | 學校財產目錄上的財產，以**資產編號**（10 碼）識別，一件一筆 |
| 保管品 | 學校「個人保管工具明細表」上的品項，有**帳面數量**，以保管人＋材料編號識別 |
| 系所物品 | 系所自己編號、可以借出的單件（例：CB-001 Chromebook、HDMI-001）；可連結保管品或固定資產，也可以是無帳物品 |
| 系所編號 | 系所物品貼紙黑框裡的號碼，格式「前綴-三位數」（COIC-001、NX2-008） |
| 保管人 | 學校帳上登記的保管人（有保管人代號） |
| 經管人 | 實際負責保管、借出的管理者（Admin 或 Super），由系統指定，不一定是學校帳上的保管人 |
| 目前位置／存放位置 | 目前位置＝實際放的地方（盤點或編輯時填）；存放位置＝學校清冊上的位置（只由匯入更新） |
| 停借 | 有處理中的異常案件時自動停借，結案後解除 |

## 共通操作

- **登入**：右上角用 Google 帳號登入。帳號要先由 Super（或 Admin 新增 User）加到名單才看得到管理功能；沒加的人登入後只看到公開頁。
- **掃 QR**：手機相機直接掃貼紙即可打開該資產頁；或在系統首頁按「掃描 QR」，把要掃的那一張放在畫面白框中間（同一張紙上有很多貼紙時，只認框內的）。貼紙掃不到時可在掃描頁下方輸入編號（資產編號、保管品 6 位數 QR 碼、系所編號如 CB-001）。
- **同時修改**：兩個人同時改同一筆時，後送出的人會看到「資料剛被修改過」，請重新整理後再改。
- **所有修改都有紀錄**：誰、什麼時候、改前改後，Super 可在「操作紀錄」查詢。

> 本手冊依系統 v0.23.0 撰寫。畫面若和手冊不同，以系統為準，並請通知 Super 更新手冊。
