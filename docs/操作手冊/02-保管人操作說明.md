# 02 保管人操作說明（User）

您的 Google 帳號由系辦綁定學校的**保管人代號**後，登入就能看到名下的財產（含所有部門）。

## 看名下的財產

1. 開 <https://cgu-coic-asset.github.io/>，右上角用 Google 帳號登入。
2. 首頁 →「我名下的財產」，分頁切換固定資產／保管品，可搜尋名稱、編號、位置。
3. 每件會顯示最近盤點日與結果。資料來自學校清冊；和實際不符請聯絡系辦。

## 自行盤點（盤點期間）

系辦建立盤點批次後，「我名下的財產」上方會出現「盤點中：○○」與截止日。

1. 到財產旁邊，按該件的「自行盤點」。
2. 拍照：
   - **固定資產三張**：全貌、資產編號貼紙特寫、廠牌型號（銘牌或序號）。三張都要清楚，學校的盤點資料表會直接用這些照片。
   - **保管品一張**全貌，並填實際數量。
3. 選結果（正常、位置不符、損壞、找不到……），東西換了地方請填「目前位置」→「送出盤點」。
4. 系辦看照片不合格會「退回」，會再出現在未盤，請重拍；或系辦到現場盤點。

## 借用與送修登記

名下的固定資產借給別的單位或送修時，可在該件「借用與送修」登記（借用部門或維修廠商、期間、借用人、經辦），回來時按「歸還／送修回來」，故障請選「故障」並說明。操作細節同 [01 管理者日常操作](01-管理者日常操作.md) 第 8 節。

## 常見問題

| 狀況 | 處理 |
| --- | --- |
| 登入後顯示「您的帳號尚未開通」 | 請系辦把您的 Google 帳號加入名單 |
| 「我名下的財產」說還沒有綁定保管人代號 | 請系辦設定保管人代號 |
| 沒看到「自行盤點」按鈕 | 目前沒有進行中的盤點批次 |
