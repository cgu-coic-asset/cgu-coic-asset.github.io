# 04 Super 每月與每年工作

Super 可以做 Admin 的所有事，另外負責帳號、備份、紀錄與系統維運。系統相關頁面在首頁「系統（Super）」區。

## 每月（約 1～5 號）

每月 1 號凌晨系統會自動：產生備份包（保留最新 12 份）、寄**月度提醒信**給所有 Super。收到信後：

1. **看提醒信**：備份是否成功、NAS 確認日、雲端容量、逾期未還、可清理的照片、待遮蔽的借用單。
2. **到 NAS 確認同步**（見 [07 NAS 設定](07-NAS設定.md)）：打開 NAS 上「資產管理系統」資料夾，抽看最近幾天的照片、借用簽核單、備份包都在。
3. 系統首頁 →「系統維運」→「NAS 已同步（設為今天）」。
4. **雲端照片清理**（有可清理項目時）：看清單 →「清理 N 項」。只會清理 NAS 確認日以前上傳、且已到期的照片（盤點照片滿一年且不是該件最近一次盤點；借還照片與簽核單結案滿 1 年），移到雲端垃圾桶（30 天內可救回），原檔在 NAS。
5. **個資遮蔽**（有待遮蔽時）：看清單 →「遮蔽 N 張」。無法復原，遮蔽後借還紀錄保留。
6. **逾期未還**：請經管人聯絡借用人。
7. **容量**：首頁或系統維運頁顯示 70%／85%／95% 警示時，先做 2～4 步；仍不夠時檢查是否有大量重複照片。

首頁「系統提醒」卡出現時（容量達門檻、NAS 超過 35 天沒確認、備份失敗或超過 35 天），也照上面處理。

## 每年

| 時間 | 工作 |
| --- | --- |
| 學校通知年度盤點時 | 建固定資產年度盤點批次（範圍全部）；保管人自行盤點＋管理者現場盤點；未盤清單追完後結束批次 |
| 盤點結束 | 「盤點資料表」列印或匯出 Word，依學校規定繳交 |
| 學校給新清冊時 | 轉檔後「匯入」，處理「待確認」的資料（學校帳上已沒有的） |
| 1 月 | 系統自動封存去年 LOG（移到「資料/LOG封存」並鎖定）；在「系統維運」確認 |
| 1 月 | 檢查帳號名單：離職、畢業的人改「停用」（不刪除，紀錄保留姓名）；確認至少兩位 Super |
| 1 月 | 檢查設定分頁（下表）是否仍符合學校規定 |

## 帳號

首頁 →「帳號」：新增或編輯 Super、Admin、User。停用不刪除。Admin 能新增、修改 User，不能動 Admin、Super。

## 設定（「系統設定」試算表的「設定」分頁）

直接在試算表改「值」欄：

| 鍵 | 預設 | 用途 |
| --- | --- | --- |
| 單位名稱 | 智慧運算學院 | 列印文件與頁首 |
| 部門代號 | D000 | 匯入時預設部門 |
| 申請提醒天數 | 3 | 申請中超過幾天顯示在首頁提醒 |
| 申請作廢天數 | 7 | 申請中超過幾天自動作廢 |
| 個資遮蔽年數 | 2 | 結案滿幾年列入遮蔽 |
| 借用照片保留年數 | 1 | 借還照片與簽核單結案滿幾年列入清理 |
| NAS確認日 | | 由「NAS 已同步」按鈕寫入，不要手動改 |
| 容量警示門檻 | 70,85,95 | 雲端用量百分比 |
| 借用通知信箱 | | 新借用申請另外通知的 Email（逗號分隔）；經管人與這裡都沒有時通知全部 Super |
| 網站網址 | https://cgu-coic-asset.github.io/ | 通知信裡的連結 |

## 查操作紀錄

首頁 →「操作紀錄」：依年份、起迄日、操作者、資產、動作、關鍵字查詢，可匯出 CSV。資產頁也有「操作紀錄」連結。

## 程式更新後

開發者更新後端時會說明要不要在 Apps Script 編輯器執行 `authorize()`（新權限）、`installTriggers()`（新排程）、`setup()`（新欄位或設定）。三個都可以重複執行，不會重複建立。
