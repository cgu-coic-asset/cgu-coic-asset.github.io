# 07 NAS 設定（Synology）

NAS 是**永久完整檔案庫**：雲端到期清理的照片、舊備份、封存的 LOG 都在 NAS 留著。系統運作不依賴 NAS，但交接重建（A 方案）需要它。

## Cloud Sync（雲端 → NAS）

DSM →「套件中心」安裝 **Cloud Sync** → 新增 → Google Drive，用**專用 Gmail** 登入授權：

| 設定 | 值 |
| --- | --- |
| 本機路徑 | 例：`/資產系統備份/資產管理系統` |
| 遠端路徑 | 雲端硬碟的「資產管理系統」整個資料夾 |
| 同步方向 | **僅下載遠端變更**（單向） |
| Google 文件 | 勾選「將 Google 線上文件轉換為 Microsoft Office 格式」（試算表會存成 .xlsx） |
| 刪除 | 勾選「**來源刪除時不刪除目的地檔案**」（雲端清理照片後 NAS 仍保留） |

設定後檢查：NAS 上有 `資料`、`照片`、`借用`、`備份`、`匯入檔` 資料夾，`資料` 內有各試算表的 .xlsx。

## 快照

DSM →「Snapshot Replication」：對放系統備份的共用資料夾開啟排程快照（建議每天一次、保留 90 天）。誤刪或檔案被覆蓋時可從快照救回。

## 權限

| 資料夾 | 誰可以讀 |
| --- | --- |
| `資產管理系統/借用`（簽核單掃描檔，含借用人個資） | **只有 Super** |
| `資產管理系統` 其他 | Super；Admin 視需要唯讀 |
| `學校資產`（手機原始照片，見 [06](06-手機照片SOP.md)） | Admin、Super 可寫入 |

## 每月確認（Super）

1. DSM → Cloud Sync：狀態「最新」，沒有錯誤。
2. 抽看 NAS 上最近的照片、簽核單、`備份` 裡上個月 1 號的備份包。
3. 系統「系統維運」→「NAS 已同步（設為今天）」。

## 換帳號重建時

照 [重建步驟](../重建步驟.md) 第 8、9 步：把 NAS 上的備份包、`照片`、`借用` 傳到新帳號還原後，Cloud Sync 改連新帳號（建議新的本機路徑，舊的資料夾保留不動）。
